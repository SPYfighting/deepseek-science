# 计算模拟总协议

本 skill 是**编排层协议**：不教具体求解器怎么写输入文件——那属于工具档案（references/tool-dossiers/）或官方手册。科学问题本身来自任务。

## 0. 强制查手册协议（铁律）

**在任何求解器上写第一行输入文件之前**，必须完成以下核验并在回复中列出：

1. **软件 + 精确版本**：远端实际安装的版本（`sci_ssh_exec` 查 `--version`/`module avail`），不是文档最新版。
2. **官方手册对应章节**：取得该版本官方文档的输入格式/关键词页（给出 URL 或手册路径）。版本 ≠ 手册版本时，以远端安装版本的手册为准。
3. **最小输入模板**：从官方示例或手册模板起步，不从记忆手写。
4. **档案登记**：把核验结果写入会话笔记（软件/版本/手册 URL/关键词差异），后续会话直接复用。

未完成核验就写输入文件 = 违规。用户明确说"跳过"时才能跳过，且要在作业记录中注明。

**新工具 8 步上手规范**（v0.9.0）：上表之外的求解器/工具/模型，完整执行
`references/universal-tool-onboarding.md` 的 8 步（版本核验→手册章节→最小模板→冒烟→见证→
生产→诊断→登记 dossier）；走完第 8 步即沉淀为新的工具档案，与本目录既有 dossier 同等使用。

## 1. 作业形态分类（先认形，再动手）

| 形态 | 典型软件 | 关键点 |
|---|---|---|
| 量子化学 | Gaussian, ORCA, Q-Chem | 基组/泛函选择、SCF 收敛、电荷与自旋多重度 |
| 分子动力学 | GROMACS, AMBER, NAMD, LAMMPS | 力场来源、拓扑构建、平衡- production 两段式 |
| 平面波 DFT | Quantum ESPRESSO, VASP | k 点收敛、截断能收敛、赝势 |
| 数值求解/偏微分 | FEniCS, COMSOL 脚本, 自写求解器 | 网格收敛性研究、边界条件 |
| 批量评分/筛选 | AutoDock, RDKit 流水线, 自写脚本 | 天然适合远程批量：单条试跑 → 放量 |

不在表内 → 当作"自定义求解器"处理，查手册协议加倍严格。

## 2. 验证阶梯（借鉴 AcademicForge compute-env-setup）

1. **冒烟**：极小体系/极少步数走通全链路（输入→运行→输出解析）。目标：验证文件格式与管道，不是科学结果。
2. **见证**：一个有已知解析解/文献基准的算例，输出与基准定量对上（误差带明确）。见证算例固化下来，每次环境变化后重跑。
3. **生产**：正式规模。产量作业前必须先过 1、2。

## 3. 提交纪律（复用 sci-remote-jobs 作业引擎）

- 结果统一写 `out/`；**中间产物（检查点、轨迹分段）也要写 out/**——崩溃时不从头来。
- walltime = 3× 预估时长；`.job_env` 传参，禁止魔法数字藏在脚本里。
- 监控：`sci_job_status` 低频轮询 + stderr 尾部早识别收敛失败/内存溢出。
- >100MB 的轨迹/波函数文件留在远端（收割自动跳过），分析脚本送过去跑，只回传汇总。

## 4. 失败诊断表

| 症状 | 层 | 处置 |
|---|---|---|
| 输入解析报错（关键词不识别） | 输入格式 | 回查该版本手册；常见原因是版本差异——不要凭记忆改 |
| SCF/平衡不收敛 | 物理/参数 | 检查初始结构、电荷/自旋、混合参数；分步弛豫；禁止无限加大步数硬扛 |
| OOM / 超时 | 资源 | 估内存（体系大小×方法标度），申请对应资源；考虑改并行度而非加大 walltime |
| 结果"跑通但离谱" | 科学设定 | 基组/力场/泛函适用域错了；回文献对照基准体系 |
| 节点上没有该软件 | 环境 | `module avail` / conda 用户态安装 / 容器（apptainer pull）；装完跑冒烟再生产 |

## 5. 报告要求

每个结果必须带：软件+精确版本、全部关键参数、随机种子（有随机性时）、收敛证据（曲线或判据值）。三者缺失的结果不得进入结论——配合 /sci-review 的 fabrication 检查。

## 工具档案

内置档案在 [references/tool-dossiers/](references/tool-dossiers/)：目前有 GROMACS、Gaussian、Quantum ESPRESSO、LAMMPS、ASE。每个档案都有"**必查项**"清单——档案给结构与已知坑，**数值仍以你查到的该版本官方手册为准**。新求解器：按 dossier 模板新建，查手册填充。
