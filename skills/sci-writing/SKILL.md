# 学术论文写作（设计参考 nature-skills/ARS 的流程思想）

## 动笔前

1. 明确目标期刊与文章类型（Article/Letter/Review）。
2. 先列大纲（IMRaD 骨架 + 每节 3-5 个要点），与用户确认后再展开。
3. 盘点已有材料：图表（`sci_figure_list`）、数据（`sci_db_query` 结果）、文献（`web_search` 检索记录 + `sci_doi_verify` 核对结论）。

## 各章节要点

- **摘要**：背景一句 → 缺口一句 → 方法两句 → 关键结果（带数字）→ 意义一句。150-250 词，禁用引用。
- **引言**：漏斗结构（领域重要性 → 已有工作 → 具体缺口 → 本文贡献）。每段一个论点，引用支撑。
- **方法**：可复现优先。写清数据来源、参数、软件版本；远程计算步骤引用作业记录。
- **结果**：图主文从，文字讲"图说明了什么"而非重复数字；统计方法与检验值齐全。
- **讨论**：结果解读 → 与文献对比 → 局限性（主动写）→ 意义与展望。

## 硬规则

- 每个数字必须能在会话执行记录或产物中溯源（配合 /sci-review 检查）。
- 引用必须真实：引用前用 `sci_doi_verify` 核对 DOI；不确定的文献宁可不引。
- 时态：方法/结果过去时，结论现在时。避免绝对化措辞（prove → demonstrate/support）。
- 拒绝 AI 腔：不用 "delve/moreover/it is worth noting"；段落长短交错；少用排比。

## 流程

1. `出大纲` → 用户确认
2. `逐节起草` → 每节完成后暂停供修改
3. `自查`：数字溯源清单 + 引用核对 → 建议 /sci-review
