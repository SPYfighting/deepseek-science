# 科研绘图开源方案调研

核对日期：2026-11-12。范围：评估 ScientificFigureLibrary（下称 SFL）及六个互补的开源工具，供 `dsh-science` 决定是否提供入口或借鉴设计。以下“事实”来自项目仓库、发布记录或期刊官方文件；“推断”和“建议”是针对本项目的判断。候选工具调研为只读核对，未安装或运行第三方工具。

落地状态：v0.13.0 已按本报告建议加入 SFL 独立可选插件入口，并实现本地 `sci_figure_plan → sci_figure_register → sci_figure_audit → 人工终审` 闭环；没有复制或内置 SFL 模板资产，也没有自动执行第三方代码。

## 结论

**建议把 SFL 作为可选的独立 dsh 插件推荐，不并入 `dsh-science`。** 它解决的是已审阅图与代码的本地保存、检索、版本化和按确认结果复制模板；不负责执行绘图，也不等于期刊图件质量审计。SFL 已提供 `dsh plugin --profile web add scientific-figure-library` 的安装路径及 MCP 工具，作为独立插件使用的开发成本低；直接内置会重复其图库、存储和授权流程，并把不同许可证的模板资产带入分发审查。[SFL README](https://github.com/xuzhougeng/ScientificFigureLibrary#readme)、[package.json](https://github.com/xuzhougeng/ScientificFigureLibrary/blob/main/package.json)、[第三方声明](https://github.com/xuzhougeng/ScientificFigureLibrary/blob/main/THIRD_PARTY_NOTICES.md)。

**图件制作方面优先保留现有 Matplotlib/ggplot2 路径，按需使用 patchwork、svgutils 和外部 Scientific-Inkscape；质量审计优先补本项目自己的、以目标期刊规则为输入的检查。** SciencePlots 属于样式预设，Bioicons/SciSVG 属于图形素材，均不能替代数据图绘制、科学审查或投稿前检验。[Nature 图件规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)、[PLOS 图件规范](https://journals.plos.org/plosone/s/figures)。

## 需求基准与本项目现状

Nature 的官方指南强调按最终尺寸评估、可编辑的矢量文字和线条，并明确指出单纯提高位图分辨率不能增加真实细节；其 Python 指南给出 `pdf.fonttype=42`。Nature 初投稿与最终投稿的要求也不同，不能把单一“300 dpi 合格”当成所有图和阶段的通用判据。[Nature 图件规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)、[Nature 初投稿要求](https://www.nature.com/nature/for-authors/initial-submission)。PLOS 也要求按目标尺寸审查，并提醒作者在其自动评估后自行检查可读性。[PLOS ONE Figures](https://journals.plos.org/plosone/s/figures)。

本地落地：`dsh-science` 保留 Matplotlib/ggplot2 主路径，登记接口现接受 PNG/JPEG/SVG/GIF/WebP/TIFF/PDF；PDF/TIFF 作为投稿文件下载查看，不强行放入浏览器图片卡。登记成功与自动前检通过都不等于期刊接收，只有清除 fail/warn 且研究者按最终尺寸留下人工终审依据后，工作台才显示“已人工终审”。[本地 sci-figures 技能](../../skills/sci-figures/SKILL.md)、[本地登记模块](../../lib/figures.js)、[前检内核](../../lib/figureqa.js)。

## 建议的落地顺序

1. **已完成：** `sci-figures` 明确计划、绘图/拼版、登记、自动前检与人工终审；工作台提供 SFL 独立安装入口和模板许可提醒，不增加其运行依赖。[本地技能](../../skills/sci-figures/SKILL.md)、[SFL dsh 安装说明](https://github.com/xuzhougeng/ScientificFigureLibrary#deepseek-harness-dsh)。
2. **需要多面板时：** R 环境用 patchwork；跨来源 SVG 尝试 svgutils。先拿一张含位图、矢量文字、中文/希腊字母的真实代表图，检查最终物理尺寸、字体保留、裁切与预览一致性，再考虑写成可复用助手。[patchwork 文档](https://patchwork.data-imaginist.com/)、[svgutils compose 文档](https://github.com/btel/svg_utils/blob/master/docs/source/compose.rst)。
3. **部分完成：** Nature 与 generic profile 已可追溯配置并计算最终尺寸有效分辨率；字体、面板、标尺、颜色、图像来源和科学真实性保留人工复核。PLOS 等 profile 尚未加入，需核对当前细则并补代表性真实图测试后再实现。[Nature 图件规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)、[PLOS ONE Figures](https://journals.plos.org/plosone/s/figures)。

## 未验证项

本调研核对的是公开仓库声明、源码配置、许可证及发布/推送记录；没有实际安装、运行、构建、绘制测试图或进行法律审查。功能能否与当前 dsh 版本、用户 R/Python 环境和目标期刊的最新细则兼容，需在决定接入时以代表性真实输入验证。GitHub `pushed_at` 不是质量或响应速度指标；第三方模板的发表权利也必须逐项核实。
